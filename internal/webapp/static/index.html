First-time Trakt app setup
  1. Open Trakt → Create API App. Sign in with your normal Trakt account if asked.
  2. Enter any app name, for example Stremio Export. Leave the other options as they are.
  3. In Trakt’s Redirect URI field, paste exactly:
    https://example.com/callback
  4. Save the app. Open it from Trakt → Your API Apps and copy its Client ID into the field below.

Use the Client ID, not the Client Secret. This app uses PKCE, so newer Trakt apps correctly show “Client Secret: Not issued.”
